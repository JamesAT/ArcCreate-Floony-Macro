# ArcCreate (ultimate?) macro
Initially maintained by Floofer++, the macro is now being enhanced
and currently maintained by James aka. Exiony.

Floony[^1] macro is probably the only macro that you'll need to make charting in [ArcCreate](https://github.com/Arcthesia/ArcCreate) easy!

## Installation:
First, find the **ArcCreate** folder and open the one named `Macros`. (If it's not there, just create a new folder and name it `Macros`).
Then pick **one** of these ways:

### Option 1: Updater (easiest, and it also keeps you up to date)
1. Download `floony_update.bat`
2. Put it inside your `Macros` folder.
3. Double-click it. It shows your installed version and the latest one, then asks what to do:
   - `I` installs the macros
   - `T` only tests (checks everything, changes nothing)
   - `C` cancels
4. Open ArcCreate (but if you have ArcCreate opened already, click **Reload macro scripts**).

To update later, just run it again. Your previous version is saved in a `floony_backup` folder next to `Macros`, so you can go back if something is wrong.

<sub>Windows may show a warning for a downloaded `.bat` file. It is plain text, so you can open it in Notepad and read exactly what it does before running it.</sub>

### Option 2: Manual
1. Download the file either through [Releases](https://github.com/JamesAT/ArcCreate-Floony-Macro/releases) or `Code > Download ZIP`.
2. Unzip the file you just downloaded.
3. Drop the files you unzipped right into the `Macros` folder.

<sub>Alternatively, you can open the zip, and drag it straight to the macros</sub>

## Highlight Features:
- **Arc Segmentation** - Create complex arc patterns with multiple generation/split methods (Zig-Zag, Ran<sub>(thunder-like pattern)</sub>, Stair, Rice, etc)
- **Arc Rain** - Generate rainfall-like traces with full control over intensity, spawn area, duration, seed, etc
- **Gradual Timing** - Self Explanatory, with a Sudden / Glitch version
- **Snap Arc** - Snap arc/trace (either start or end) position onto the selected arc
- **Align & Distribute** - line up or space out the selected arcs.
- **Notes to Trace** - Transform various note types (floor, hold, arc, arctap) into traces/void
- **Camera Effects** - Add numerous camera events with blank, repeat, flick, bounce functionalities
- **Note Trails** - Create trailing visual effects by generating timing groups with gradually dissapearing note sequences
- **Auto-Quantize** - Automatically quantize selected notes to beatline (follows BPM changes)
- **Density / Progress** - Track chart progress, visualize note density with a heatmap, and calculate notes per second.
- **Chart Category Check** - Tells you if your chart is Standard, Special or NotARCAEA, and what breaks the rules.
- **Favorites** - Pin the macros you use most, and see your most used ones automatically.
- **Updater (floony_update.bat)** - Install or update the macro with one simple click.
- **And so much more!**

[^1]: Floony is a combination name of (Floo)fer++ and Exio(ny).
